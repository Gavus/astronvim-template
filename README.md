# AstroNvim Config

**NOTE:** This is for AstroNvim v6+

My personal config for AstroNvim

## 🛠️ Installation

### Ubuntu: Noble dependencies

```shell
./install-debian-dependencies.sh
```

### Install using script

Downloads a tested nvim version and removes all old nvim configs, and cached
files.

```shell
./install.sh -r
```

### Quick install

Simply run this command in the terminal to do clean install.

```shell
curl -s \
  https://raw.githubusercontent.com/Gavus/astronvim-config/main/install.sh \
  | bash /dev/stdin -r
```

### Start Neovim

```shell
nvim
```
